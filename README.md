# Калькулятор зарплаты

Статический сайт (HTML + CSS + JS, без сборки и сервера). Считает зарплату и аванс по часам,
ночным, праздничным и выходам в выходной по формуле:

```
(часы × (ставка + премия) + ночные × доплата_ночь + (праздничные + выходные) × доплата_праздник) × коэффициент
аванс (1–15 число) = (часы × ставка + ночные × доплата_ночь + праздничные × доплата_праздник) × коэффициент   — без премии
на руки = начислено × (1 − НДФЛ)
```

Все ставки, график и правки дней хранятся в localStorage браузера — у каждого свои, на сервер ничего не уходит.

## Деплой на Vercel
Вариант 1 — через CLI, из этой папки:
```
npx vercel          # предпросмотр
npx vercel --prod   # боевой адрес
```
Framework Preset: **Other**, Build Command — пусто, Output Directory — `.` (корень).

Вариант 2 — залить папку в GitHub-репозиторий и импортировать его на vercel.com/new.

## Локально
Открыть `index.html` в браузере.
